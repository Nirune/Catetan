# Catetan

Aplikasi catatan sederhana untuk Android.

## Fitur

- Buat, lihat, edit, dan hapus catatan
- Warna catatan dapat diatur (6 palet)
- Tema: Terang / Gelap / Ikuti sistem
- Ekspor semua catatan ke format `.ctn` (JSON Catetan)
- Ekspor satu catatan ke TXT / JSON / MD
- Impor catatan dari file `.ctn` / `.txt` / `.json` / `.md`

## Build

```bash
cd /path/to/Catetan
./gradlew assembleDebug
```

APK akan ada di `app/build/outputs/apk/debug/app-debug.apk`.
